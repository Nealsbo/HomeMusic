# HomeMusic

[English](README.md) · **Русский**

Лёгкий личный музыкальный сервер с веб-плеером для компьютеров и телефонов.
Храните коллекцию на Windows или Linux и слушайте её с устройств в локальной
сети

## Возможности

- Медиатека с альбомами, исполнителями, папками, поиском и обложками
- Плейлисты, импорт и экспорт M3U/M3U8, избранное и история прослушивания
- Независимые очереди устройств, удалённое управление и перенос воспроизведения
- Загрузка файлов, редактор метаданных, проверка коллекции и отмена поддерживаемых изменений
- Английский и русский интерфейс, темы и настройка размеров текста и иконок

## Быстрый запуск

Нужен **Python 3.10+** с поддержкой SQLite. Сторонние Python-пакеты и сборка
интерфейса не требуются. Необязательные **FFmpeg/ffprobe** позволяют читать теги
и извлекать обложки.

Скачайте или клонируйте проект. По умолчанию музыка читается из папки `Music`,
расположенной рядом с папкой проекта:

```text
parent/
├── HomeMusic/
└── Music/
```

Выполните из папки проекта:

**Windows** — командная строка или PowerShell:

```powershell
.\run-windows.bat
```

**Linux:**

```bash
bash run-linux.sh
```

Откройте `http://localhost:8080` на сервере или `http://IP-СЕРВЕРА:8080` на другом
устройстве. Для остановки сервера нажмите **Ctrl+C**.

## Настройка

По умолчанию: `--listen true --host 0.0.0.0 --port 8080 --music-dir "../Music/"`.
Параметры можно переопределить при запуске:

```powershell
.\run-windows.bat --music-dir "D:\Music" --port 8090
```

```bash
bash run-linux.sh --music-dir "/srv/music" --port 8090
```

Для доступа только с этого компьютера используйте `--listen false`
(`127.0.0.1`). Параметры `--host` и `--ip` равнозначны.

Чтобы сохранить настройки, скопируйте [config.example.json](config.example.json)
в `config.json` и отредактируйте его. Файл загружается автоматически; аргументы
запуска имеют приоритет над ним. Относительные пути отсчитываются от папки
проекта. Все параметры: `python main.py --help` (на Linux — `python3`).

Дополнительные музыкальные директории настраиваются списком `music_sources`
в конфиге. Они объединяются в одну медиатеку; подробнее — [STORAGE.md](STORAGE.md).
Цветовые схемы вынесены в отдельные файлы `web/themes/`; устройство набора —
[THEMES.md](THEMES.md).

Перезапуск с перечитыванием конфига доступен в настройках сервера и TUI
(`S`, затем `y`, либо `python tui.py --restart`). Нужен запуск через `main.py`
и ключ владельца. Подробнее — [RESTARTING.md](RESTARTING.md).

## Обновления

Раздел «Настройки → Обновления» проверяет опубликованные релизы и устанавливает
их с перезапуском. Для установки нужен ключ владельца из консоли сервера.
Автоматическая проверка выполняется раз в сутки; установка — вручную. Музыка
и конфигурация сохраняются, а при неудачном запуске восстанавливаются предыдущая
версия и база. Подготовка релизов и восстановление описаны в [UPDATING.md](UPDATING.md).

## Особенности

Звук воспроизводится в браузере подключённого устройства. Поддержка кодеков
зависит от браузера; сервер не перекодирует аудио. Коллекция, плейлисты,
избранное и история общие, а очереди воспроизведения независимы.

HomeMusic предназначен для доверенной локальной сети и не имеет авторизации
пользователей. Язык интерфейса выбирается в настройках и сохраняется в этом
браузере. Добавление переводов описано в [LOCALIZATION.md](LOCALIZATION.md).
