Operation log

Undo metadata edits, playlist creation, deletion, contents and order, M3U imports, and file moves here. If the same data was changed later, undo the later changes first. Undoing metadata restores manual edits over the current file tags.

To undo a move, the original folder must exist, the return path must be free, and the file must match the saved size, modification time, and file system ID. The log retains up to 500 operations for 30 days, with a snapshot size limit; redo is not supported.
